## Sobre

Repositorio de referencia com codigos Arduino para sensores, motores, comunicacao e utilitarios. Cada sketch e independente e pode ser aberto direto no Arduino IDE.

---

## Estrutura

`
raidens-arduino/
├── sensors/        # Codigos de sensores
├── motores/        # Controle de motores
├── comunicacao/    # I2C, SPI, Serial
├── utilitarios/    # Funcoes auxiliares
└── examples/       # Projetos completos
`

---

## Sensores

| Sensor | Modulo | Funcao |
|---|---|---|
| HC-SR04 | ultrassonico/ | Medicao de distancia |
| TCRT5000 | infravermelho/ | Deteccao de linha |
| TCS3200 | cor/ | Deteccao de cor |
| MPU6050 | girosencopio/ | Aceleracao e giro |
